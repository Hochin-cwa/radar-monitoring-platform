# 需求文件：環境溫溼度監測

## 簡介

在雷達監控整合平台新增環境溫溼度監測功能，於衛星作業科下加入溫溼度計（IP: 192.168.178.19），提供溫度與濕度歷史趨勢圖表，使操作人員能掌握機房或設備環境變化。

---

## 詞彙表

- **溫溼度計（Environment Monitor）**：部署於衛星作業科的環境感測設備，定期回報溫度（°C）與濕度（%RH）。
- **IP**：溫溼度計網路位址 192.168.178.19。
- **歷史趨勢圖**：以時間為 X 軸，溫度或濕度為 Y 軸的折線圖。

---

## 需求

### 需求 1：儀器列表加入溫溼度計

**使用者故事：** 身為操作人員，我希望在儀器即時狀況頁面的衛星作業科下看到溫溼度計的即時狀態卡片，以便一併監控環境條件。

#### 驗收標準

1. THE 儀器即時狀況頁面 SHALL 在衛星作業科分組中顯示溫溼度計（IP: 192.168.178.19）的狀態卡片。
2. WHEN 操作人員點擊溫溼度計卡片，THE Platform SHALL 在新分頁開啟溫溼度計歷史資料頁面。

---

### 需求 2：溫溼度歷史趨勢頁面

**使用者故事：** 身為操作人員，我希望看到溫溼度計的溫度和濕度隨時間變化的折線圖，以便判斷環境是否異常。

#### 驗收標準

1. THE 歷史資料頁面 SHALL 顯示溫度（°C）時序折線圖。
2. THE 歷史資料頁面 SHALL 顯示濕度（%RH）時序折線圖。
3. THE 歷史資料頁面 SHALL 提供時間範圍選擇器（6h、1d、1w、1m、3m）。
4. WHEN 操作人員切換時間範圍，THE 頁面 SHALL 重新取得資料並更新圖表。
5. THE 頁面結構（header、時間範圍按鈕、圖表區塊）SHALL 與既有 history.html 保持一致。
6. IF 指定時間範圍內無資料，THE 頁面 SHALL 顯示「此時間範圍內無資料」提示。

---

### 需求 3：後端 API

**使用者故事：** 身為前端頁面，我需要透過 REST API 取得溫溼度歷史資料。

#### 驗收標準

1. THE Platform SHALL 提供 `GET /api/v1/history/environment?ip=...&range=...` 端點。
2. THE API 回應 SHALL 包含 `temperature` 和 `humidity` 兩個陣列，每筆含 `time`（ISO8601）和 `value`。
3. THE API SHALL 從 SystemStatus 資料庫的 `EnvironmentStatus` 表讀取溫溼度歷史記錄。
4. THE API SHALL 支援 range 參數：6h、1d、1w、1m、3m。
